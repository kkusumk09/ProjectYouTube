# 🎬 ProjectYouTube — YouTube UI Clone

A YouTube-inspired website built using **HTML and CSS** to practise front-end web development, page layout, and styling.

## 📌 About the Project

ProjectYouTube is a front-end practice project that recreates the visual structure of YouTube. It focuses on building a structured webpage with reusable styling and distinct layout sections.

The project helped me strengthen my understanding of HTML page structure and CSS styling while exploring how modern video-sharing platforms organise their interfaces.

## ✨ Features

- **YouTube-Inspired Interface:** A webpage layout modelled after YouTube's visual design.
- **Structured Header:** A dedicated header section for the main navigation area.
- **Sidebar Layout:** Separate styling for the sidebar section.
- **Video Section Styling:** CSS dedicated to the video content layout.
- **Modular CSS Files:** Styles organised into separate files for better readability and maintainability.
- **Responsive Design Practice:** A foundation for exploring layout adjustments across different screen sizes.

> Note: Features such as responsive behaviour and interactive controls should only be considered implemented if they are supported by the current code.

## 📂 Project Structure

```text
ProjectYouTube/
│
├── Youtube.html
├── General.css
├── Header.css
├── Sidebar.css
├── Video.css
└── README.md
```

### File Overview

- `Youtube.html` — Main webpage structure.
- `General.css` — General styling and shared page styles.
- `Header.css` — Styling for the header section.
- `Sidebar.css` — Styling for the sidebar.
- `Video.css` — Styling for the video section and related elements.
- `README.md` — Project documentation.

## 🚀 Getting Started

You can run this project locally without installing additional packages.

### 1. Clone the Repository

```bash
git clone https://github.com/kkusumk09/ProjectYouTube.git
```

### 2. Open the Project Folder

```bash
cd ProjectYouTube
```

### 3. Run the Website

Open `Youtube.html` in your preferred web browser.

You can also open the project folder in a code editor, such as Visual Studio Code, to explore and modify the HTML and CSS files.
